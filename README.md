# Cùng Con Cất Tiếng (v6)

Ứng dụng web sàng lọc nguy cơ RLPTK (M-CHAT-R/F™) & mốc ngôn ngữ CDC/ASHA cho trẻ 12–36 tháng.

## Cách mở nhanh trên điện thoại
1. Giải nén file zip (nếu tải file zip) để lấy file `index.html`.
2. Mở file `index.html` bằng Chrome hoặc Safari trên điện thoại.

## Cách đưa lên mạng (GitHub Pages miễn phí)
1. Tạo một repository mới trên GitHub (ví dụ: `cung-con-cat-tieng`).
2. Tải file `index.html` lên thư mục gốc của repository.
3. Vào **Settings > Pages**, chọn nhánh `main` và thư mục `/ (root)` rồi bấm **Save**.
4. Chờ vài phút để nhận link web chạy trực tiếp (`https://<ten-tai-khoan>.github.io/cung-con-cat-tieng/`).
